# 도메인 상수 부록 (v2 `saturation_calc` 활성화 시 사용)

> `docs/prd.md`(§1~§10)에서 분리된 부속 문서입니다. `docs/prd.md` §11 "관련 문서"에서 링크됩니다.

> ⚠️ **활성화 가능성 재평가(담당자 확인, `docs/prd.md` §10-6)**: 사내 "포화도"는 셀 전체/세퍼레이터 기준을 사양별로 나눠 관리하고, 관리 타겟은 계산형(이론치)이되 실측도 병행한다는 것까지는 확인됐다. 그러나 **정확한 계산식(공극 부피 산출 방법)은 담당자도 정확히 모르며 설계 기밀일 가능성이 있다.** 즉 아래 상수·역산식을 이용한 `saturation_calc` 활성화는 "시간이 지나면 확보되는 v2 항목"이 아니라 **확보 자체가 실패할 수 있는 스트레치 목표**로 취급해야 한다. MVP·v2 설계 모두 "결국 실제 포화도를 계산하게 될 것"을 전제로 하지 말고, 잔존율(retention rate) proxy가 장기적으로도 주력 지표로 남을 가능성을 기본 시나리오로 둔다.

검증된 이론값이나, `docs/prd.md`의 §10 Open Question #1(Z 후보 판별)·§10-7(water_loss SOP)에서 확인했듯 이번 더미 데이터의 실측 `water_loss`와는 자릿수 단위로 차이가 나므로 **그대로 적용하지 말고 실 SOP 확인 후 사용**할 것.

- 유효 화성 1 Ah당: H₂SO₄ **+3.66 g** 방출(극판→액), 물 **−0.672 g** 소모 → 액 질량 순 **+2.99 g**
- 과충전 1 Ah당: 물 전기분해 **0.336 g** 손실 (전지 중량 감소로 나타남)
- 전지 **전체** 중량 기준이면 극판→액 황산 이동은 내부 이동이라 상쇄되므로, `water_loss`는 외부 유출분만 잡는다
- 액 질량 역산 (화성 후 비중 확보 시):
  `m₁ = [ m₀·(1 − 0.817·c₀) − water_loss ] / (1 − 0.817·c₁)`, `V₁ = m₁ / ρ₁`, `S = V₁ / V_void × 100`
  (`c` = 황산 질량분율, 비중 환산 시 온도보정 필수)
- 해석 주의: 액 부피는 거의 변하지 않는데도 포화도가 떨어지는 경우가 많다. 화성으로 **분모(극판 공극)가 커지기 때문**이다. 원인진단 규칙이 무조건 "주액량 증대"로 향하지 않도록 설계할 것.
