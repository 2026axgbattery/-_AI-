**2026-09-26 재점검**: 튜터 조언 방향(검증 최우선)을 잘 따라가고 있는지 사용자 요청으로 재확인함 —
§0 채점 결과는 `history/26`(더미 1만 행 확장 + 신호 반영) 이후 4개 타깃 전부 90% 임계값을 통과하도록

검증용 더미 형명 2개(AGM60/70_S1)만 채워져 있고 실제 운영 대상 33개 형명은 여전히 비어 있어(아래
