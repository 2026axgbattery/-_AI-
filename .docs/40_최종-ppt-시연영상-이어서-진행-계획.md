# 40. 최종 PPT 재작성 + 시연 영상 — 끊긴 지점부터 이어서 진행 (2026-09-30)

## 배경

`sebang-skills`를 설치해 (1) 보고서 PPT를 sebang-deck으로 다시 만들고 (2) demo-video로 시연 영상을 만들던 중 세션이 끊겼다(구독 접근 차단 메시지). 끊긴 시점의 상태:

| 항목 | 상태 |
|---|---|
| 스킬 3종 설치(`~/.claude/skills`) | 완료 |
| ffmpeg/ffprobe, Chrome(`~/Applications`), Playwright(`~/node_modules`), Node 24 | 설치 완료 |
| 1차 PPT(양식 그대로 채움, `...김경준.pptx`) | 완료, 단 스킬 미사용본 |
| 2차 PPT(sebang-deck 재작성) | **미착수** — 실제 화면 캡처 단계에서 중단 |
| 시연 영상 | **미착수** (사용자 결정: 시연 영상 + 무음/자막본) |
| 배포 서비스 | Vercel 200, Render 정상이나 **DB가 비어 있음**(무료 티어 휘발성) |

## 범위

1. 배포된 Render 백엔드에 더미 데이터·충전 프로그램 기준표를 다시 반영하고 회귀·채점을 실행(화면에 결과가 보이도록).
2. 실제 배포 화면을 캡처해 sebang-deck으로 2차 PPT를 **새 파일**로 저장(1차본 보존).
3. demo-video로 배포 URL 조작 시연 영상을 무음(`--estimate`) + 자막으로 제작.

## 방법 · 완료 기준

- 데이터 반영은 `.docs/39` 6절과 동일한 절차(`/api/upload/*`, `/api/charge-program/upload`, 회귀 API).
- PPT: `render.py`로 전 페이지 렌더 후 넘침·겹침 확인, 숫자는 실측 API 값만 사용.
- 영상: `timeline.json`의 녹화/나레이션 길이 점검, 컷 시트로 조작 결과 확인.
- ElevenLabs 키가 없어 음성은 없음(자막·무음). 키가 생기면 `tts.py` 한 번으로 음성 추가 가능.

## 진행 결과 (2026-09-30)

- Render 백엔드에 충전 프로그램 기준표 → 더미 공정(4,992행)·시험(300건) 업로드, 1·2단·CCA 회귀와 채점 4종 실행 완료.
- PPT v2: `AX전문가과정_과제개발결과보고서_창원품질경영팀 김경준_v2.pptx` (8쪽, sebang-deck, 실제 배포 화면 캡처 3장, 링크 3개 하이퍼링크, validate 통과·전 페이지 렌더 확인). 1차본은 그대로 보존.
- 시연 영상: `제출물_영상/시연영상_AI포화도예측_무음자막.mp4`(72초, 1080p, 무음) + `시연영상_자막.srt`. `demo_project/`에 demo.json 보관 — ElevenLabs 키가 생기면 `tts.py`→`check_tts.py`→`compose.py`로 음성 추가.
- 알려진 이슈: (1) `/prediction`의 "예시값으로 채우기" 값이 현재 더미 데이터 스케일과 안 맞아 Z=1.3%로 나옴(`frontend/lib/diagnosis.ts`의 `X_COLUMN_EXAMPLES`). 영상은 실제 스케일 값을 직접 입력해 회피. (2) Render 무료 서버에서 미매칭 4,692건 일괄 예측은 수 분 걸려 영상에서 제외. (3) 채점 Z·EN CCA는 86.7%로 90% 기준 미달 — PPT에 그대로 표기.

## 추가 작업 — 전 기능 시연 영상 v2 (2026-09-30)

- 요청: (1) 시험(Z) 결과가 없는 로트도 예측하는 기능(시험 전 로트 일괄 예측)을 영상에 추가, (2) 모든 기능을 확인해 자세히 소개, (3) 녹화·자막 재작성.
- 방법: Render 무료 서버는 일괄 예측 4,692건이 241초 걸려 녹화 불가 → 같은 코드·같은 더미 데이터를 로컬(백엔드 8010 + 프런트 3010, `AX_DB_PROFILE=scratch`)에 올려 녹화(일괄 예측 8초). 화면 하단 태그는 "배포된 실제 웹앱"이 아니라 "실제 웹앱 · 더미 데이터"로 표기.
- 장면 구성: 업로드(미리보기→반영·매칭·수기입력·이력) → 대시보드(분석 실행·결론·근거·CCA·채점) → 상세 조회(범위 전환·게이지·미달 로트 원인·추이) → 예측(조건 시뮬레이션, 시험 전 로트 일괄 예측 4개 보기).
- 완료 기준: 컷 시트로 장면별 조작 결과 확인, 자막(srt)·대본 파일 저장.
- 결과: `제출물_영상/시연영상_전기능_무음자막.mp4`(약 290초, 15개 조작 장면) + `시연영상_전기능_자막.srt` + `전기능_나레이션_대본.md`. 로컬 서버는 종료·임시 DB 삭제 완료. 1차 영상(72초)은 보존.
- 2분 이내 축약본: `제출물_영상/시연영상_2분이내_무음자막.mp4`(78.6초) + srt. 업로드·대시보드 그래프·상세 추이·조건 예측·시험 전 로트 일괄 예측(날짜/형명/바이어 그래프)만 포함.
