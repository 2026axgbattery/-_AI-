# 결과 우선(Result-First) 대시보드 구조 개편 계획

## 배경/동기
`output/analysis_dashboard.html`, `output/04_prediction.html` 두 화면은 현재 상관계수·회귀계수·VIF 같은 통계 근거가 화면 상단부터 나열돼 있어, 비전문가가 "지금 상태가 좋은지 나쁜지"를 한눈에 파악하기 어렵다. 사용자는 (1) 결론(양품/부적합 여부, 핵심 수치)을 최상단에 크게 보여주고, (2) 그 근거(상관·회귀·VIF 등)는 눌러야 펼쳐지는 compact한 영역으로 옮기고, (3) 근거 안에서 "왜 이런 값이 나왔는지"(원인진단)까지 이어서 확인할 수 있는 3단 구조를 요청했다.

## 범위
- 대상 파일: `output/analysis_dashboard.html`, `output/04_prediction.html` (정적 HTML 목업, 순수 프레젠테이션 계층만 변경 — 수치·더미 데이터는 그대로 유지)
- 비범위: 새로운 분석 로직, 실제 데이터 재계산, 다른 화면(업로드·수기입력·상세분석) 구조 변경

## 방법
1. **Layer 1 — 결론 요약 (항상 보임, 화면 최상단)**: Y·Z 각각의 종합 판정(양품/부적합)을 큰 배지·숫자로 보여주는 히어로 섹션 신설. 세방 디자인 토큰(오렌지=위험/그린-700=양호) 사용, 두 포인트컬러 동시 강조 금지 원칙 준수.
2. **Layer 2 — 근거 (기본 접힘, 클릭 시 펼침)**: 기존 상관계수/회귀계수/VIF/베이스라인 비교/일괄 예측 표를 네이티브 `<details>/<summary>`로 감싸 compact화. summary는 docs/design.md 카드 헤더 스타일 유지.
3. **Layer 3 — 원인 상세**: 기존 "SPEC 판정 & 원인진단" 카드를 근거 섹션과 연결된 별도 상세 보기로 유지하되, Layer 1에서 바로 진입 가능한 링크/버튼 제공.
4. 자바스크립트는 최소화(네이티브 `<details>` 토글 활용, 앵커 스크롤 정도만 추가).

## 완료 기준
- 화면 첫 스크롤에서 Y/Z 판정과 핵심 수치가 바로 보임(추가 클릭 없이).
- 상관계수·회귀계수 등 통계 근거는 기본적으로 접혀 있고 클릭해야 펼쳐짐.
- 근거 섹션에서 원인진단(왜 이런 값이 나왔는지)으로 자연스럽게 이어짐.
- 기존 세방 디자인 토큰·컬러 규칙(docs/design.md) 위반 없음.
- 브라우저 프리뷰로 두 화면 모두 렌더링 확인.
