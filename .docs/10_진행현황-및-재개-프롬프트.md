- **v2(10월) 실행 순서**(`.docs/23` 기준, `.docs/22` §3): 1) 합격선 확정(완료) → 2) 실제 데이터 1개월치 반영(예정, 더미가 아닌 실측 데이터 축적) → 3) 채점·이상 여부 확인(1차 완료, 실데이터 축적 후 재확인 예정) → 4) 재학습 규칙 정하기(미정) → 5) 학습 데이터 최적화(미정). R²/RMSE 정식 검증·train/val 분리, 캐스케이드 vs 베이스라인 정량 비교 리포트도 미착수.
