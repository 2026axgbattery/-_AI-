# 11. 데스크톱 패키징 검토 (Tauri)

> Next.js+FastAPI 웹앱을 데스크톱 애플리케이션(.exe) 형태로도 배포할 수 있는지에 대한 검토 메모. 2026-09-10 대화에서 사용자 질문에 답하며 나온 내용을 정리했다. **지금 시점에는 검토만 하고 실제 설치·스캐폴딩은 진행하지 않기로 결정**(사용자 확인).

## 결론

가능하며, 이 프로젝트 조건(창원공장 폐쇄망 내 단일 프로세스 로컬 실행, 외부 네트워크 호출 금지)과 잘 맞는 방향이다. 다만 **3일 MVP 기한 내에는 진행하지 않고, v2 이후 "사내 배포" 단계 과제로 미루는 것을 권장**한다 — `.docs/04_기술-스택-정의서.md` §2.6에서 이미 "사내 배포"를 MVP 이후 단계로 정의하고 있어 방향이 일치한다.

## 옵션 비교: Electron vs Tauri

| 항목 | Electron | Tauri |
|---|---|---|
| 렌더러 엔진 | Chromium 번들 (자체 포함) | Windows 내장 WebView2 (OS 제공, 재사용) |
| 런타임 | Node.js 번들 | Rust |
| 설치 파일 크기 | 수백 MB | 수십 MB |
| 리소스 사용 | 상대적으로 큼 | 상대적으로 작음 |
| 폐쇄망 배포 적합성 | 보통 | 좋음 (설치 파일 작고 의존성 적음) |

**추천: Tauri.** 설치 파일이 작고 리소스를 덜 쓰며, 창원공장 폐쇄망처럼 배포·업데이트가 번거로운 환경일수록 이점이 크다.

## 현재 코드 구조와의 궁합

`.docs/02_nextjs-fastapi-구현-아키텍처.md`가 정의한 Next.js(`frontend/`)+FastAPI(`backend/`) 분리 구조는 그대로 유지된다. Tauri는 Next.js를 렌더러(WebView)로 감싸고, FastAPI를 백그라운드 사이드카(sidecar) 프로세스로 앱 시작 시 함께 띄우는 형태로 붙는다. 즉:

- 웹앱으로 먼저 개발 → 나중에 Tauri 셸로 감싸는 순서가 자연스럽다(코드 재작성 불필요, 래핑만 추가).
- `backend/analysis/`를 웹 프레임워크에 비의존적인 순수 Python으로 분리해두라는 기존 원칙(`.docs/02` 참조)이 이 경로에서도 그대로 유효하다.
- SQLite 파일 경로만 "실행 파일 옆" 또는 "OS 표준 앱데이터 폴더"로 바꿔주면 된다(웹앱 단계의 로컬 파일 방식 설계를 그대로 재사용).

## 추가로 필요한 것 (실제 착수 시 체크리스트)

현재 이 PC 환경 점검 결과(2026-09-10 기준):

| 도구 | 상태 | 비고 |
|---|---|---|
| Node.js / npm | 설치됨 (`v24.20.0` / `11.19.0`) | 그대로 사용 가능 |
| Python / pip | 설치됨 (`3.14.7` / pip `26.2.1`) | 그대로 사용 가능 |
| Rust (`rustc`/`cargo`) | **미설치** | Tauri 빌드에 필수 — `rustup`으로 설치 필요 |
| Tauri CLI | 미설치 | Rust 설치 후 `cargo install tauri-cli` 또는 `npm create tauri-app` |
| Microsoft C++ Build Tools | 미확인 | Windows에서 Rust 빌드 시 필요(Visual Studio "C++를 사용한 데스크톱 개발" 워크로드). 별도 설치 프로그램, 용량이 수 GB로 큼 |
| WebView2 Runtime | 대부분 Win10/11에 기본 내장 | 최신 Windows Update가 돼 있으면 보통 이미 있음 — 실제 착수 시 재확인 필요 |

실제 착수 시 예상 절차 (참고용, 지금은 실행하지 않음):
1. `rustup-init.exe` 설치 → `rustc`/`cargo` 확인
2. Visual Studio Build Tools("C++를 사용한 데스크톱 개발" 워크로드) 설치 확인/설치
3. `npm create tauri-app@latest` 또는 기존 `frontend/`에 `@tauri-apps/cli` 추가
4. FastAPI를 사이드카 바이너리(PyInstaller 등으로 패키징)로 번들하거나, 개발 중에는 로컬 프로세스로 별도 실행
5. SQLite 경로를 Tauri의 앱데이터 디렉터리 API로 연결

## 결정 사항

- 이번 대화에서는 **검토 메모 작성까지만 진행**하고 실제 Rust/Tauri 설치나 프로젝트 스캐폴딩은 하지 않기로 함(사용자 선택).
- MVP 3일 집체는 계획대로 **브라우저 웹앱(Next.js+FastAPI)** 으로 완결한다.
- 데스크톱 패키징이 필요해지는 시점에 이 문서의 체크리스트를 참고해 착수한다.
