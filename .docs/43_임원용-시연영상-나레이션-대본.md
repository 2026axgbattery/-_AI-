# 43. 임원용 시연 영상 나레이션 대본 (2026-10-21 v9: 대본 화면 매칭 보강, 부족한 점·앞으로를 1챕터로 통합)

대상: 임원(비전공자). 길이: 약 3분 45초(영상 2분 37초 + 직접 발표 약 1분 05초). 수치는 더미 데이터 기준 실측값(`.docs/42`).

## 1. 오프닝 (0:00~0:20) — 화면: 타이틀 카드 + "95%"
안녕하세요, 창원품질경영팀 김경준입니다. 시험 결과를 시험하기 전에 미리 맞히는 프로그램을 소개합니다. 합격인지 불합격인지를 95% 맞혔고, 어떻게 만들었고 무엇이 부족한지 보여드리겠습니다.

## 2. 왜 필요한가 (0:20~0:50) — 화면: 시험 대기 도식
배터리 성능인 20시간 용량과 저온 시동 성능은 시험이 끝나야 알 수 있고, 그동안에도 같은 조건의 제품은 계속 만들어집니다. 미달이 나오면 이미 많이 만든 뒤입니다. 그래서 시험을 기다리지 않고, 만들 때의 조건만으로 미리 알 수 없을까 생각했습니다.

## 3. 어떻게 만들었나 (0:55~1:24) — 화면: SPC 공정 데이터 업로드 → 포화도 → 제품 성능 2단 도식(클릭 한 번·자동)
방법은 단순합니다. SPC에 입력되어 관리되는 공정 데이터를 올리기만 하면, 사람이 계산하지 않아도 자동으로 예측이 이어집니다. 먼저 전해액이 얼마나 잘 채워졌는지, 즉 포화도를 예측합니다. 그 결과로 20시간 용량과 저온 시동 성능, 즉 제품의 성능을 확인합니다.

## 4. 95%는 어떻게 쟀나 (1:26~2:08) — 화면: 240건/60건 분할 도식 → 57/60 카운트업
그럼 95%는 어떻게 쟀을까요. 시험을 마친 제품 300건 가운데 240건으로 프로그램을 가르쳤습니다. 그리고 한 번도 보여주지 않은 60건으로 시험을 쳤습니다. 외운 문제를 다시 푸는 것이 아니라, 처음 보는 문제를 푸는 방식입니다. 채점 기준은 점수 차이가 아니라, 합격인지 불합격인지가 실제와 같은가입니다. 60건 중 57건이 맞았고, 이것이 95%입니다. 저희는 90%를 넘으면 믿을 만하다고 기준을 정했는데, 포화도는 이 기준을 넘었습니다. 저온 시동 성능 두 가지도 90%와 93%로 기준을 충족했습니다.

## 5. 화면 시연 (2:09~2:37) — 화면: 실제 웹앱 녹화(업로드·대시보드·조건 변경 예측)
화면으로 보겠습니다. 공정 데이터를 올리면 시험 결과와 자동으로 짝지어집니다. 대시보드에서는 전체 평균과 합격 현황이 한눈에 보입니다. 공정 조건을 바꿔 입력하면 포화도와 용량이 바로 다시 계산되고, 합격선과 비교한 결과가 나옵니다. 불합격이 예상되면 어떤 조건의 영향이 큰지 순서대로 보여줘서, 무엇을 고쳐야 하는지 바로 알 수 있습니다.

## 5-2. 추가 기능 소개 (약 30초) — 화면: 실제 웹앱 녹화(업로드 미리보기 → 분석 실행·검증 신뢰도 → 상세 분석 게이지 → 미달 로트 원인 → 형명별)
추가로 기능을 소개해 드리겠습니다. 파일을 고르면 저장하기 전에 미리보기로 먼저 확인합니다. 분석은 버튼 한 번이면 끝나고, 예측이 믿을 만한지도 신뢰 기준과 비교해 바로 알려 줍니다. 상세 화면에서는 포화도, 20시간 용량, 저온 시동 성능의 합격 현황을 한눈에 보고, 기준에 못 미친 제품은 원인이 되는 조건 세 가지까지 바로 짚어 줍니다. 형명별, 바이어별로 좁혀 보는 것도 클릭 한 번입니다.

## 6. 시험 없이 나머지 로트까지 (확장 예측) (2:37~2:55) — 화면: 300건 학습 → 4,692건 예측 도식 + 시험 전 로트 일괄 예측 화면
그리고 이것이 가장 큰 장점입니다. 성능 시험을 마친 제품으로 학습해서, 아직 시험하지 않은 나머지 로트의 20시간 용량까지 미리 예측합니다. 그래서 시험을 여러 번 돌리지 않아도, 공정 데이터만 올리면 전체 로트의 결과를 한 번에 확인할 수 있습니다.

## 7. 정리: 얻는 것 (2:56~3:10) — 화면: 얻는 것 3가지 카드
정리하면, 데이터만 올리면 합격 여부를 미리 알고, 시험하지 않은 로트까지 한 번에 확인하고, 고칠 조건까지 바로 알 수 있습니다.

## 8. 부족한 점과 앞으로의 변화 (3:17~3:42, 직접 발표 약 25초) — 화면: 항목별 일치율 표(용량 86.7% 강조) → 마무리 카드
부족한 점도 있습니다. 20시간 용량은 86.7%로 기준 90%에 못 미쳤고, 지금은 연습용 가상 데이터라 현장에서 95%가 그대로 나온다고 말씀드릴 수는 없습니다. 앞으로 실제 데이터로 다시 검증하고, 시험 결과가 쌓일 때마다 다시 배우게 하겠습니다. '시험 후에 대응하는 품질'에서 '만들 때 미리 막는 품질'로 바꾸겠습니다. 감사합니다.
