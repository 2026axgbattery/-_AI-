# 44. 임원 영상 — 용어 설명 도입부(3D) 추가 + As-Is/To-Be 설명 보강 (2026-10-22)

## 배경

- 현재 최종본 `하이브리드_최종_v9.mp4`(2분 37초) + 직접 발표로 총 3분 42초가 나와, 5분 이내 중 4분 30초 안팎으로 늘리고 싶다.
- 임원은 AGM 배터리·포화도·20시간 용량·CCA를 모를 수 있어, 본편 앞에 그림과 3D로 쉽게 정의하는 도입부가 필요하다.
- 직접 발표의 "왜 필요한가"가 짧아, 현재(As-Is: SPC로 데이터는 들어오지만 사람이 직접 분석해 시간이 걸림)와 개선(To-Be: 업로드만 하면 포화도부터 제품 성능까지 확인) 및 만든 과정을 더 자세히 말해야 한다.

## 범위

| 항목 | 내용 | 분량 |
|---|---|---|
| 직접 발표 2장 개편 | As-Is → 왜 불편한가 → To-Be → 만든 3단계(연결·영향 계산·검증) | 25초 → 약 45초 |
| 영상 도입부(신규) | AGM 구조 3D → 포화도 → 20시간 용량 → CCA(저온 시동) | 약 30초 |
| 기존 본편(v9) | 변경 없음, 도입부 뒤에 이어 붙임 | 2분 37초 |
| 대본 PPT | 해당 장 수정 + 용어 설명 장 추가 | - |

예상 합계: 직접 발표 약 1분 25초 + 영상 약 3분 07초 = 약 4분 30초대.

## 방법

- 도입부: three.js(로컬 설치)로 3D 장면을 만들고 Chrome(Playwright)으로 프레임 캡처, 세방 CI(Ink/Green, 워드마크) 준수. 새 포인트색 추가 없음.
- 나레이션: 기존은 ElevenLabs(Sarah)이나 이 컴퓨터에 API 키가 없다. 임시로 macOS 한국어 음성으로 합성해 길이·화면 동기화를 검증하고, 키가 있는 컴퓨터에서 같은 스크립트로 음성만 교체해 재렌더한다.
- 합성: 도입부 mp4 + v9를 이어 붙인다(본편 원본은 보존, 새 파일로 저장).

## 완료 기준

- 도입부 4개 정의가 나레이션 문장 시작 시각에 맞춰 화면에 나타난다(컷 시트로 확인).
- 영상 속 수치·정의가 기존 문서와 모순 없음(포화도=전해액이 채워진 정도, 20시간 용량, CCA=영하 18℃ 시동 성능).
- 합계 시간을 계산해 4분 30초 안팎임을 확인, 대본 PPT 렌더 확인.

## 결과 (2026-10-22)

- 도입부 약 29초(임시 음성 기준): AGM 배터리 3D 단면 → 포화도(스펀지에 전해액이 차오름, 0→95% 카운트) → 20시간 용량(셀이 서서히 방전, 0→20시간 링) → 저온 시동 성능(영하 18℃·눈·시동 펄스). 컷 시트로 4개 장면 확인.
- `제출물_영상/하이브리드_최종_v10.mp4` = 도입부 + v9, 총 3분 6초(185.97초). v9는 보존.
- 직접 발표 2장을 "현재(As-Is)와 개선(To-Be), 만든 과정"(약 45초)으로 개편, 대본 PPT 14쪽(용어 설명 장 추가)·PDF 갱신.
- 시간 합계(추정): 15초 + 45초 + 186초 + 25초 = 약 271초 ≈ 4분 30초. 실제 합계는 발표 속도에 따라 ±.
- **한계**: 이 컴퓨터에 ElevenLabs 키가 없어 도입부 음성은 macOS 임시 음성이다(본편은 Sarah). 키가 있는 컴퓨터에서 `제작소스/도입부/make_voice.py`로 교체 후 재렌더해야 목소리가 통일된다(make_voice.py는 키가 없어 미실행). 목소리를 바꾸면 도입부 길이가 3~5초 늘 수 있다.
