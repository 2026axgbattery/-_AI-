# 33. 배경 톤다운 + 그래프 임팩트 강화(Recharts 도입 + 그림 기반 표현 확대) 계획

## 배경/동기

사용자가 (1) 전체 배경을 더 어두운 톤으로, (2) 그래프가 더 눈에 띄도록 개선을 요청 — 질문을 통해
방향을 좁혔다:
- 배경: **라이트 테마 유지, 톤만 살짝 다운**(흰 배경 대신 세방 라이트그레이 계열, 완전 다크모드 아님).
- 그래프: **정적인 div 막대 대신 실제 차트 라이브러리 도입** + **배터리 게이지 같은 "그림 기반" 표현 확대**.
- 범위: **화면 전체의 모든 그래프·막대**.

작업 착수 전 `dataviz` 스킬을 로드해 절차를 따른다(색상은 마지막에 결정, 폼 선택 → 색상 배정 → 검증
스크립트 실행 → 마크 스펙 → 호버 레이어 → 접근성 순).

## 스킬 적용 — 폼/색상 판단

- 이 앱의 기존 "카테고리 순서"(dark-gray→green→orange→gray-400, `docs/design.md`)를 스킬의 검증
  스크립트로 실제 확인한 결과: **진짜 카테고리(식별) 팔레트가 아니라 상태(status) 팔레트**였다
  (dark-gray·gray-400은 채도가 낮아 "정체성 색상"이 아니라 구조색/비활성색 — 스킬의 categorical
  6항목 검증은 이 조합에 그대로 적용되지 않음, WCAG 텍스트 대비만 해당). 실제로 앱의 모든 막대는
  ①부호(+/−) 표시(상관계수·회귀계수 막대 — dark-gray/gray-400) 아니면 ②양품/부적합/판정불가
  상태(GroupBarChart — green-700/orange/gray-400) 둘 중 하나로, 이름이 다른 5개 이상의 항목을
  색상 하나로 구분해야 하는 진짜 categorical 상황은 없다. → **기존 색상 그대로 유지**, 새 팔레트
  설계 불필요. 상태 색상은 원래 규칙대로 아이콘/라벨과 항상 같이 표기.
- 폼 선택: 상관계수·회귀계수는 막대(가로 bar, 크기=|값|, 색=부호) 그대로가 맞는 폼 — 실제
  라이브러리(Recharts)로 다시 그리되 마크 스펙(4px 라운드 끝, 2px 갭, 호버 툴팁)만 강화.
  형명별/바이어별/날짜별 판정 분포는 100% 누적 가로 막대(그대로), 추이는 라인 차트(그대로).

## 범위

1. **배경 톤다운**: `frontend/lib/theme.css`의 `--color-bg-base`(흰색 → 세방 라이트그레이 계열)만
   변경. 카드(`--color-bg-surface`)는 흰색으로 올려 배경과 카드의 명암 대비를 오히려 더 뚜렷하게
   만든다(지금은 배경 흰색/카드 옅은 회색이라 거의 구분이 안 됨 — 반전하면 카드가 도드라져 보임).
2. **Recharts 도입**(`npm install recharts`, React 19 호환 확인 완료) — 아래 차트를 교체:
   - `/dashboard`: 상관계수 막대(heat-bar) · 회귀계수 막대(coef-track) → Recharts 가로 BarChart.
   - `/detail-analysis`: 형명별 Y 추이(inline SVG polyline) → Recharts LineChart.
   - `/prediction`: 형명별/바이어별/날짜별 판정 분포(GroupBarChart) → Recharts 가로 100% 누적
     BarChart.
   - 공통: 마크 4px 라운드, 세그먼트 간 2px 갭, 호버 시 툴팁(카테고리+정확한 값), 값은 막대 끝에
     직접 라벨(공간 없으면 툴팁으로).
3. **그림 기반 표현 확대**: 대시보드 히어로의 Y/Z/CCA 평균 지표 3개(`.hero-metrics`, 지금은 숫자
   텍스트만)에 `BatteryGauge`와 같은 시각 언어의 소형 라운드 게이지를 추가 — 배터리 게이지처럼
   "그림으로 바로 읽히는" 표현을 히어로(제일 먼저 보는 곳)까지 확장.
4. 범위 밖(다음 후속으로 남김): 모든 텍스트 KPI를 게이지화(과함, 클러터 위험) · 완전 다크모드 ·
   scatter/choropleth류(현재 앱에 해당 폼 자체가 없음).

## 완료 기준

- `npm run build`/`npm run lint` 통과, `pytest`/`ruff`는 백엔드 변경이 없으므로 스킵.
- 각 차트가 호버 시 정확한 값을 보여주고, 막대 끝 라벨이 잘리지 않으며, 2px 갭·4px 라운드가
  실제로 적용됨(코드 리뷰로 확인, 브라우저 자동화 도구 부재로 스크린샷 확인은 생략).
- 배경 톤 변경 후에도 본문 텍스트 대비가 기존 대비표(§2.6) 기준을 유지.
