# 45. 도입부 Sarah 음성 교체 + 포화도 역할 부연 + 화면 완성도 개선 (2026-10-22)

## 배경
- v10 도입부(용어 설명 약 29초)는 macOS 임시 음성이라 본편(ElevenLabs Sarah)과 목소리가 다르다.
- 사용자 요청: (1) 도입부 음성을 본편 Sarah로 통일, (2) 포화도가 하는 역할을 5~10초(긴 버전, 약 8초) 부연, (3) 그림 완성도 향상. 대본은 사용자가 승인함.

## 승인된 대본
1. 먼저, 오늘 나오는 용어를 쉽게 짚고 가겠습니다.
2. 에이지엠 배터리는 유리 섬유 판이 전해액을 스펀지처럼 머금고 있는 배터리입니다.
3. 포화도는 이 유리 섬유 판에 전해액이 얼마나 가득 찼는지를 나타내는 비율입니다. **전해액이 부족하면 전기가 흐르는 길이 줄어서, 용량도 저온 시동 성능도 떨어질 수 있습니다. 그래서 포화도는 시험 전에 제품 성능을 미리 가늠하는, 가장 중요한 중간 지표입니다.**
4. 20시간 용량은 20시간에 걸쳐 일정하게 꺼내 쓸 수 있는 전기의 양입니다.
5. 그리고 저온 시동 성능, 씨씨에이는 영하 18도의 추위에서 시동을 거는 힘입니다.

## 방법
- 음성: 본편과 같은 voice(Sarah, `EXAVITQu4vr4xnSDxMaL`)·`eleven_multilingual_v2`·`with-timestamps`로 한 번에 합성 → 문장별 시각을 얻어 화면 타이밍에 사용. 키는 `제출물_영상/.env.elevenlabs`에서 읽기만 한다.
- 화면: 포화도 장면을 3박자(정의 → 부족하면 → 중간 지표)로 확장. 첫 장면 우측 용어 개요, 20시간 링 확대, 저온 장면 눈·링이 글자와 겹치지 않게 정리, 장면 전환 페이드.
- 합성: 새 도입부 + v9 본편 → `하이브리드_최종_v11.mp4`(v10은 보존).

## 완료 기준
- 문장 시작 시각마다 해당 화면이 나타남(컷 시트 확인), 글자 겹침·잘림 없음, 최대 음량 -1dB 이하.
- 도입부 약 37초, 전체 약 3분 14초(합계 5분 이내).
- `.docs/43`·대본 PPT에 추가 문장 반영.
