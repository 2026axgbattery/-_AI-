이번 개편에서 바뀐 점

  1. 실물 배터리 사진 채움 그림 — 도형 대신 세방전지 ROCKET AGM 배터리 실제 제품 사진(gbattery.com 공개 이미지)을 케이스 외곽선에 딱 맞게 크롭해 사용, 흐리게 깔린 원본 위로 %만큼 아래에서부터 또렷해지는 방식으로 표현. 표를 읽지 않아도 한눈에 상태 파악 가능.
  2. 게이지가 배터리 케이스 안에서만 채워짐 — 사진 바깥 여백(단자 위쪽 흰 배경)까지 채워지던 문제를 수정. 사진을 배터리 외곽에 맞춰 미리 크롭하고, 게이지 기준선을 "단자를 뺀 케이스 몸통 윗면"(--battery-case-top)으로 잡아 100%여도 케이스 라인을 넘어가지 않음.
  3. 페이지 진입마다 차오르는 게이지 — 이전에는 처음부터 결과값이 채워진 채로 표시됐지만, 이제 이 화면에 들어올 때마다(새로고침·뒤로가기 복귀 포함) 게이지와 숫자가 0%에서 시작해 실제 값까지 차오르는 애니메이션으로 보여줌(prefers-reduced-motion 설정 시 애니메이션 없이 바로 최종값 표시).
  4. 5초 주기 강조 — 채우기 애니메이션이 끝난 뒤에도, 결론 배너의 핵심 숫자와 배터리 위 % 숫자가 5초마다 한 번씩 살짝 커지며 빛나 시선을 붙잡음(prefers-reduced-motion 설정 시 자동으로 꺼짐).
  5. 글자 크기 한 단계 확대 — 본문 16px → 18px, 캡션 12~13px → 15px, 결론 배너는 22px로 이 화면에서 가장 크게.
  6. 처음 보는 사람 기준 설명 — "포화도"·"20시간 용량" 같은 용어를 정의부터 풀어 쓰고, 숫자가 왜 좋은지/나쁜지까지 한 문장으로 덧붙임.
  7. 상단 한줄 결론 — 형명·기간·두 지표·SPEC 판정 결과를 표 위로 올려, 화면에 들어오자마자 "지금 상태"를 파악할 수 있게 함.
