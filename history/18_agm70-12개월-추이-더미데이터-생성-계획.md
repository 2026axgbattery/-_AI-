# 17. AGM70 단일 형명 12개월 추이 더미 데이터 생성 계획

> **완료(2026-09-11)**: `scripts/generate_agm70_trend_dummy.py`로 계획대로 생성 완료. `agm70_trend_process_data.csv`(1,200행, lot_id 유일), `agm70_trend_test_data.csv`(24행, lot_id 유일)를 저장소 루트에 생성했고, 두 파일의 24개 시험 lot_id가 전부 공정 데이터에도 존재해 매칭됨을 확인(공정 실측 보존 20건 중 시험 실측 12건 + 실측 12건을 확보한 나머지 12개월의 더미 시험행은 같은 달 합성 공정 lot_id에 매칭)했다. NaN 없음, 월별 100행 균등 분포 확인.

## 배경/동기

사용자가 `AGM 시험현황_raw data.xlsx`(모델 헤더 `AGM70`, 20개 샘플의 초기상태 실측값 + 그중 12개 샘플의 20HR 용량 시험 실측값을 담은 실제 raw data, `.docs/14` 참조)를 근거로, 단일 형명 하나에 대해 **12개월간 꾸준히 생산된 공정 데이터(월 100건×12개월=1,200행)**와 **그 공정 데이터에 매핑되는 시험 데이터(월 2건×12개월=24행)**를 만들어 1년치 추이(Day2 상세분석 "형명별 추이" 화면)를 확인할 수 있는 더미 데이터를 요청함. 형명(서브형명)은 사용자 확인 결과 `AGM70_S1`(기존 `templates/spec_thresholds_template.csv`에 이미 등록된 6개 AGM70 서브형명 중 하나)로 지정. 신규 생성 데이터는 기존 `process_data.csv`(100행)·`test_data.csv`(59행)와 별도 파일로 분리한다(기존 두 CSV는 `correlation-reliability-review.md`에 인용된 p-value·상관계수의 근거 데이터라 덮어쓰지 않음, 사용자 확인).

## 범위

- 신규 파일 2개, 저장소 루트에 생성: `agm70_trend_process_data.csv`(1,200행), `agm70_trend_test_data.csv`(24행). 컬럼 구성은 기존 `process_data.csv`/`test_data.csv`와 동일.
- 앱 업로드 화면(`/upload`)으로 그대로 올릴 수 있어야 하며, `lot_id` 매칭(공정↔시험)이 실제로 동작해야 한다.

## 방법

1. **raw data 파싱**: `AGM 시험현황_raw data.xlsx`에서 20개 샘플의 초기상태(전압/내부저항/중량/주액량/감액량/완성중량/1차완성OCV/1차완성일/MT(V)/MT(A))와, 그중 12개 샘플의 20HR 용량(1차) 시험 실측값(방전량/충전량/용량%/충전율%)을 그대로 추출한다.
2. **공정 데이터 1,200행 구성(월 100건×12개월, model_name=AGM70_S1 고정)**:
   - 실제 20개 샘플의 `lot_id`를 원본 그대로 보존한 행 20개를 월별로 분산 배치한다(시험 실측이 있는 12개 샘플은 이후 시험 데이터와 동일 월에 배치해 실제 매칭이 성립하도록 함).
   - 나머지 중 절반(월 100건 중 약 50건, 20개 실측 보존행 제외분 580건)은 20개 실측 샘플의 `fill_weight`/`water_loss`/`voltage_1st`/`voltage_2nd` 값을 그대로 재사용(부트스트랩)하되 `lot_id`는 새로 발급해 "실제 데이터를 절반 섞음" 요건을 충족한다.
   - 나머지 절반(월 100건 중 약 50건, 총 600건)은 기존 `process_data.csv`의 AGM70 서브형명 18행에서 산출한 평균/표준편차를 따르는 순수 합성값으로 채운다.
   - raw에 없는 컬럼(`cell1~6_weight/ginap`, `bath_no`, `circuit_no`, `soaking_time_sec`, `aging_days`, `charge_amount`, `electrolyte_temp`, `tank_temp`, `line_no`)은 실측 보존행 포함 전 행에서 기존 AGM70 데이터의 평균/표준편차 기반 합성값으로 채운다(raw 파일 자체에 해당 필드가 없으므로 100% 합성).
3. **시험 데이터 24행 구성(월 2건×12개월)**: raw의 실측 12건을 1건씩 12개월에 배치(실제 데이터를 모두 소진)하고, 나머지 12건(월 1건씩)은 실측 12건의 통계 특성(평균/표준편차)을 따르는 합성값으로 채워 24행을 완성한다. 실측 12건의 `lot_id`는 공정 데이터의 해당 실측 보존행과 동일하게 맞춰 매칭이 성립하게 한다.
4. 생성 스크립트는 재현성을 위해 고정 시드(`numpy.random.default_rng(42)`)를 사용한다.

## 완료 기준

- 두 CSV 파일이 생성되고 행 수(1,200/24)·컬럼 헤더가 기존 CSV와 동일함을 확인한다.
- `lot_id`가 파일 내에서 유일하고, 실측 12개 `lot_id`가 두 파일에 공통으로 존재해 매칭 가능함을 확인한다.
- 생성 스크립트 실행 로그로 실측/합성 비율(공정 20+580 실측기반 vs 600 합성, 시험 12 실측 vs 12 합성)을 보고한다.
