# 16. 대시보드 "결과 우선(Result-First)" 구조 재정렬 계획

> **완료(2026-09-11)**: 아래 계획대로 `frontend/app/dashboard/page.tsx`·`components.css`를 수정했다. `next build`/`eslint` 통과, Playwright로 실제 앱 콘솔 에러 없음 + mock 데이터로 Layer 1 문장 생성·Layer 2 펼침/접힘 렌더링 확인. 상세 내용은 `.docs/07_디자인-수정-이력.md`(9) 참조.

## 배경/동기

`.docs/01_결과우선-대시보드-구조개편-계획.md`에서 `output/analysis_dashboard.html` 목업에 이미 "Layer 1(결론 요약, 항상 보임) → Layer 2(근거, 클릭 시 펼침) → Layer 3(원인 상세)" 3단 구조를 적용해 두었다. 그러나 실제 Next.js 구현(`frontend/app/dashboard/page.tsx`)은 이 구조를 반영하지 않고 상관계수·회귀계수 카드가 화면 상단부터 그대로 나열돼 있다(`CLAUDE.md`에 "verdict-banner 등은 Day 3로 이월됐다"고 기록됨).

사용자가 재확인을 요청: "결국 이 분석으로 무엇을 확인했는지"를 전문용어 없이 최상단에서 바로 이해할 수 있고, 그다음에 근거 자료를 눌러서 확인하는 흐름으로 목업 방향을 최대한 지금 반영해 달라는 것. 단, SPEC 임계값 판정·원인진단(⑤)은 아직 Day 3 미착수 상태이므로, 목업의 "SPEC 미달 N건" 같은 배지는 **지어낼 수 없다**(`CLAUDE.md` 원칙 — Day 2는 SPEC 판정을 넣지 않기로 이미 결정됨). 대신 지금 실제로 계산되는 상관·회귀 결과에서 "무엇이 확인됐는지"를 평이한 문장으로 자동 요약하는 방식으로 Layer 1을 채운다.

## 범위

- 대상: `frontend/app/dashboard/page.tsx`, `frontend/app/components.css`
- 비범위: SPEC 판정 배지·원인진단(Layer 3 "왜 이런 값이 나왔나")·미매칭 로트 일괄 예측 표(Layer "일괄") — 전부 Day 3 스코프라 이번에는 만들지 않는다. `frontend/app/detail-analysis/page.tsx`도 비범위(`.docs/01`에서 원래도 비범위로 명시).

## 방법

1. **`components.css`에 누락된 클래스 추가**: `output/analysis_dashboard.html`의 `.verdict-banner`, `.verdict-row`/`.verdict-card`(SPEC 판정이 없으므로 fail/ok 대신 중립 `status-info` 톤), `details.evidence` 접이식 스타일을 기존 디자인 토큰(`--sebang-*`, `--space-*`, `--radius-*`) 그대로 사용해 이식한다.
2. **Layer 1(결론 요약, 항상 보임)** 신설: `xToY`/`xyToZ` 결과에서 가장 유의미한(|r| 최대이면서 p<0.05) 인자를 찾아 "○○이(가) 클수록/작을수록 포화도(Y)가 높아지는/낮아지는 경향이 가장 뚜렷했습니다" 식의 평이한 문장을 자동 생성하고, 2단 결과가 있으면 "포화도(Y)가 20시간 용량(Z)에 주는 영향" 한 줄을 덧붙인다. 유의미한 인자가 없으면 그 사실을 그대로 알린다(과장 금지). SPEC 판정 문구는 넣지 않고, "SPEC 임계값 판정은 아직 연동 전(Day 3 예정)"이라는 사실만 짧게 덧붙인다.
3. Layer 1 아래 보조 카드 2개(Y 요약/Z 요약, 표본 수·평균값 등 실측 수치)는 `status-info`(중립) 톤으로 배치 — fail/ok 배지는 SPEC이 없는 한 사용하지 않는다.
4. **Layer 2(근거, 기본 접힘)**: 기존 "1단 X→Y" 섹션 전체(흐름도 + 상관계수 카드 + 회귀계수 카드)와 "2단 X+Y→Z + 베이스라인" 섹션 전체를 각각 네이티브 `<details class="evidence">`로 감싼다. `summary`에는 목업과 동일하게 무엇을 볼 수 있는지 힌트를 붙인다.
5. 분석 미실행 상태(`!xToY`)에서는 Layer 1을 "아직 분석 결과가 없습니다" 안내로 대체하고 근거 섹션은 렌더링하지 않는다(기존 동작 유지).

## 완료 기준

- 대시보드 첫 화면에서 클릭 없이 "이번 분석으로 확인된 것"이 평이한 문장으로 보인다.
- 상관계수·회귀계수·VIF 등 통계 근거는 기본적으로 접혀 있고 클릭해야 펼쳐진다.
- SPEC 판정·원인진단 등 Day 3 미구현 내용을 지어내지 않는다(기존 "Day 3 연동 예정" 원칙 유지).
- `design.md`/기존 토큰 재사용, 새 색상 없음. 오렌지·그린 동시 강조 금지 원칙 준수.
- `next build`/`eslint` 통과, 브라우저 프리뷰(Playwright)로 실제 렌더링·콘솔 에러 없음을 확인.
