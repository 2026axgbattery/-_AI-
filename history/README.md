# history 폴더 — 참조 금지 안내

이 폴더에는 **더 이상 활성 참조 대상이 아닌** 과거 산출물을 보관한다. 각 파일은 이미 최신 문서로 대체됐거나(예: v2 기획서), 특정 시점의 1회성 산출물(세션 로그, 실행 완료된 프롬프트, 구버전 압축본)이라 현재 작업에 재사용할 근거가 없다.

## 지시사항 (Claude Code 및 협업자 공통)

- **이 폴더의 파일은 코드 작성, 문서 작성, 의사결정의 근거로 참조하지 않는다.** 현재 유효한 내용은 저장소 루트와 `.docs/`의 최신 문서에 있다.
- 최신 문서와 내용이 충돌하면 **항상 최신 문서가 우선**하며, 이 폴더의 내용은 오래된 스냅샷일 뿐이다.
- 과거 경위나 결정 배경이 궁금할 때만 "역사적 기록"으로 열람한다 — 이 경우에도 여기 적힌 수치·구조·계획을 그대로 인용하지 말고, 반드시 최신 문서(`prd.md`, `.docs/*`)의 해당 내용을 다시 확인한다.
- 새 문서를 작성할 때 이 폴더의 파일을 링크·인용하지 않는다.
